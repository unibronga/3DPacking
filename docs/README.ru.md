## Зачем

Вы точно знаете, что коробка с проводами *где-то* в кладовке. 3DPacking хранит живую 3D-модель ваших комнат, шкафов, стеллажей и коробок: что в каждой лежит, сколько осталось места, и фото каждой вещи. Это программа для компьютера — все данные остаются у вас.

## Возможности

- 🧱 **Вложенные контейнеры** — комнаты, шкафы, стеллажи, коробки и вещи с любой глубиной вложенности. Кольца заполненности показывают, сколько места занято.
- 📚 **Каталог реальных предметов** — начните вводить название и выберите из 1600+ настоящих вещей и их заводских коробок (IKEA, Samsung, LG, Bosch, Philips, переездные коробки, паллеты…): настоящие габариты подставятся сами. Поиск прощает опечатки, понимает транслит и неверную раскладку. Каждый размер взят из официального источника.
- 🖱️ **Ручная расстановка** — тащите вещи прямо в сцене: они падают на пол и друг на друга, прилипают к стенкам и соседям, а отпущенные над шкафом или коробкой — перекладываются внутрь. Кнопки **Повернуть 90°** и **На бок** ставят вещь в любое из шести положений.
- 📦 **Плотная автоукладка** — 3D bin packing: крайние точки, опора не меньше 70 %, повороты, «пустые» предметы можно класть на бок, перебор порядков и локальный поиск в бюджете времени. Переключите контейнер в **Авто** — и он будет перекладываться при каждом изменении.
- 🔍 **Удобная навигация** — выбор сквозь прозрачные стенки, перелёт камеры к любому объекту, виды 3D / сверху / спереди / сбоку, хлебные крошки, поиск.
- 📷 **Фото, заметки и свои поля** — вставьте или перетащите фото на любой объект (хранится локально, сжимается в WebP), добавьте заметки и собственные поля.
- ↩️ **Можно смело пробовать** — автосохранение, отмена и повтор всего (целое перетаскивание — один шаг), экспорт и импорт в JSON вместе с фото.
- 🎨 **Оформление под себя** — шесть тем от «Графита» до PixelArt, восемь текстур фона, режим Дзен, размер интерфейса 80–200 %, пиксельный 3D.
- 🌍 **Семь языков** — English, Русский, Українська, Deutsch, Nederlands, Français, Español — включая меню и встроенную справку (`F1` или `?`).

## Скачать

Возьмите **3DPacking-mac-arm64.zip** из [последнего релиза](https://github.com/unibronga/3DPacking/releases/latest), распакуйте и перенесите **3DPacking.app** в «Программы».

> Приложение подписано сертификатом Developer ID и заверено Apple — открывается как любая другая программа для Mac.

## Сборка из исходников

Нужен Node.js 20+.

```bash
npm install
npm run dev       # в браузере: http://localhost:5288
npm run desktop   # окно Electron
npm run app       # release/mac-arm64/3DPacking.app
npm run i18n      # проверить, что во всех языках есть все строки
```

## Горячие клавиши

| Клавиша | Действие | Клавиша | Действие |
| --- | --- | --- | --- |
| `N` | Новый объект | `A` | Расставить плотно |
| `F` | Показать выбранное | `Z` | Режим Дзен |
| `G` | Режим перемещения | `,` | Настройки |
| `H` | Скрыть / показать | `?` / `F1` | Справка |
| `⌘D` | Дублировать | `[` `]` | Левая / правая панель |
| `⌘Z` / `⇧⌘Z` | Отменить / повторить | `⌥` + клик | Выбрать контейнер |
| `⌫` | Удалить | `Esc` | Снять выбор |

## Как устроено

Vite + чистый JavaScript + [three.js](https://threejs.org) r180 + Electron — без фреймворков.

| Файл | Что делает |
| --- | --- |
| `src/store.js` | Данные: плоский список с `parentId`, размеры и положение в см, отмена и повтор на снимках |
| `src/packing.js` | Плотная 3D-укладка |
| `src/viewport.js` | Сцена, выбор, перетаскивание с гравитацией и прилипанием, перелёты камеры |
| `src/i18n.js`, `src/locales/` | Языки: ключ — русская строка, словарь каждого языка даёт перевод |
| `src/ui/` | Дерево слева, инспектор, окна, настройки, справка |
| `electron/` | Окно программы и переведённое меню |

### Как добавить язык

Скопируйте `src/locales/en.js`, переведите значения, добавьте язык в `LANGS` в `src/i18n.js` и в `electron/menu-i18n.cjs`, затем запустите `npm run i18n`.

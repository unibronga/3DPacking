## Навіщо

Ви точно знаєте, що коробка з дротами лежить *десь* у коморі. 3DPacking зберігає живу 3D-модель ваших кімнат, шаф, стелажів і коробок: що в кожній лежить, скільки лишилося місця, і фото кожної речі. Це програма для комп’ютера — усі дані залишаються у вас.

## Можливості

- 🧱 **Вкладені контейнери** — кімнати, шафи, стелажі, коробки й речі з будь-якою глибиною вкладеності. Кільця заповненості показують, скільки місця зайнято.
- 🖱️ **Ручне розставлення** — тягніть речі просто в сцені: вони падають на підлогу й одна на одну, прилипають до стінок і сусідів, а відпущені над шафою чи коробкою — перекладаються всередину.
- 📦 **Щільне автоукладання** — 3D bin packing: крайні точки, опора щонайменше 70 %, повороти, «порожні» предмети можна класти на бік, перебір порядків і локальний пошук у межах бюджету часу. Перемкніть контейнер в **Авто** — і він перекладатиметься після кожної зміни.
- 🔍 **Зручна навігація** — вибір крізь прозорі стінки, переліт камери до будь-якого об’єкта, вигляди 3D / згори / спереду / збоку, хлібні крихти, пошук.
- 📷 **Фото, нотатки й свої поля** — вставте або перетягніть фото на будь-який об’єкт (зберігається локально, стискається у WebP), додайте нотатки й власні поля.
- ↩️ **Можна сміливо пробувати** — автозбереження, скасування й повтор усього (ціле перетягування — один крок), експорт та імпорт у JSON разом із фото.
- 🎨 **Оформлення під себе** — шість тем від «Графіту» до PixelArt, вісім текстур тла, режим Дзен, розмір інтерфейсу 80–200 %, піксельне 3D.
- 🌍 **Сім мов** — English, Русский, Українська, Deutsch, Nederlands, Français, Español — разом із меню та вбудованою довідкою (`F1` або `?`).

## Завантажити

Візьміть **3DPacking-mac-arm64.zip** з [останнього релізу](https://github.com/unibronga/3DPacking/releases/latest), розпакуйте й перенесіть **3DPacking.app** до «Програм».

> Застосунок підписано сертифікатом Developer ID і завірено Apple — він відкривається, як будь-яка інша програма для Mac.

## Збирання з вихідного коду

Потрібен Node.js 20+.

```bash
npm install
npm run dev       # у браузері: http://localhost:5288
npm run desktop   # вікно Electron
npm run app       # release/mac-arm64/3DPacking.app
npm run i18n      # перевірити, що в усіх мовах є всі рядки
```

## Гарячі клавіші

| Клавіша | Дія | Клавіша | Дія |
| --- | --- | --- | --- |
| `N` | Новий об’єкт | `A` | Розставити щільно |
| `F` | Показати вибране | `Z` | Режим Дзен |
| `G` | Режим переміщення | `,` | Налаштування |
| `H` | Сховати / показати | `?` / `F1` | Довідка |
| `⌘D` | Дублювати | `[` `]` | Ліва / права панель |
| `⌘Z` / `⇧⌘Z` | Скасувати / повторити | `⌥` + клік | Вибрати контейнер |
| `⌫` | Видалити | `Esc` | Зняти вибір |

## Як влаштовано

Vite + чистий JavaScript + [three.js](https://threejs.org) r180 + Electron — без фреймворків.

| Файл | Що робить |
| --- | --- |
| `src/store.js` | Дані: плаский список із `parentId`, розміри й положення в см, скасування й повтор на знімках |
| `src/packing.js` | Щільне 3D-укладання |
| `src/viewport.js` | Сцена, вибір, перетягування з гравітацією та прилипанням, перельоти камери |
| `src/i18n.js`, `src/locales/` | Мови: ключ — російський рядок, словник кожної мови дає переклад |
| `src/ui/` | Дерево ліворуч, інспектор, вікна, налаштування, довідка |
| `electron/` | Вікно програми й перекладене меню |

### Як додати мову

Скопіюйте `src/locales/en.js`, перекладіть значення, додайте мову до `LANGS` у `src/i18n.js` і до `electron/menu-i18n.cjs`, потім запустіть `npm run i18n`.

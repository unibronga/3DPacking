# 3DPacking

Десктоп-программа (Electron) для склада в 3D: контейнеры (комнаты, шкафы, коробки) и вещи внутри них, ручная расстановка мышью и плотная автоматическая укладка. Дизайн — «стеклянный», в духе CleanMyMac, с темами и режимом Дзен.

Стек: Vite + vanilla JS + three.js r180 + Electron. Без фреймворков. Комментарии и тексты интерфейса — по-русски.

## Команды

```bash
npm run dev       # браузер, http://localhost:5288
npm run desktop   # сборка страницы + окно Electron
npm run app       # release/mac-arm64/3DPacking.app (без dmg)
npm run icon      # build/icon-source.png → build/icon.png (плитка macOS)
npm run catalog   # обновить src/data/catalog.csv из ~/AI_Projects/разное/3dpacking-catalog
npm run dist      # значок + сборка установщика
```

После `npm run app` приложение подписывается ad-hoc (`codesign --force --deep --sign - …app`) и копируется в `/Applications/3DPacking.app` (`ditto`) — системные «Программы», именно там пользователь его ищет. Ярлык на рабочем столе — alias Finder на него.

Релиз для других (подпись Developer ID + нотаризация + zip): `npm run release:mac` (`scripts/release-mac.sh`). Нужны сертификат «Developer ID Application: Timchenko Konstantin (T5NKRQA9H4)» в связке ключей и профиль notarytool `3dpacking-notary`. Подпись Electron — несколько сотен файлов с меткой времени (~10 мин), нотаризация — ещё 5–15 мин; запускать в фоне. Выпуск на GitHub: `gh release create vX.Y.Z release/3DPacking-mac-arm64.zip`; пуш — через deploy key (`core.sshCommand` в `.git/config`).

Самопроверка собранного приложения в окне 1600×1000 (без разворота):

```bash
PACKING_SELFTEST=1 PACKING_WINDOWED=1 PACKING_SCREENSHOT=/tmp/app.png release/mac-arm64/3DPacking.app/Contents/MacOS/3DPacking
```

## Устройство

- `src/store.js` — данные: плоский список с `parentId`, размеры и `pos` в **см** (угол относительно внутреннего угла родителя). Undo/redo — снимки; жест мышью (`source: 'gesture:…'`) = один шаг. Расстановка контейнера: `arrange: 'manual' | 'auto'`.
- `src/packing.js` — 3D bin packing: крайние точки + проекции, опора ≥ 70 %, повороты (на бок — только «пустые» предметы с `tilt`), перебор порядков/правил + локальный поиск в бюджете времени. Тесты качества — гонять вручную на наборах (кубы, повороты, смесь).
- `src/viewport.js` — сцена (1 ед. = 1 м): сетка-шейдер, выбор сквозь прозрачные стенки, перетаскивание (`beginDrag/updateDrag/endDrag`, плоскость через точку захвата, прилипание, «гравитация», перекладывание в контейнер под центром), анимация переезда, гизмо `G`.
- `src/themes.js` — темы (CSS-переменные + цвета сцены + палитра), размер интерфейса 80–200 % (`--ui`, через `zoom` на панелях), настройки в localStorage `sklad3d:prefs`.
- `src/catalog.js` — каталог реальных предметов (`src/data/catalog.csv`, размеры в см, грузится лениво отдельным чанком) и поиск по нему: префикс, опечатки, русские синонимы, транслит и раскладка; точные совпадения всегда выше опечаточных. Подсказки под полем названия в окне создания — `src/ui/suggest.js` (с 3-й буквы; выбор подставляет имя, габариты, тип и свойства «Бренд»/«Источник»). Русские слова для поиска пишутся в обратных кавычках, иначе `npm run i18n` примет их за ключи перевода.
- `src/photos.js` — фото объектов в IndexedDB (`sklad3d-photos`), в объекте только `photo: id`; при добавлении — сжатие до 2000 px в WebP; при запуске `gc` удаляет фото без ссылок; экспорт JSON кладёт фото в `photos: { id: dataURL }`. Лайтбокс — `src/ui/lightbox.js`.
- `src/ui/` — `sidebar.js` (дерево + свёрнутая полоска), `inspector.js` (правая панель), `modal.js`, `settings.js`, `help.js` (справка, `F1`/`?`), `dom.js` (хелпер `h()`, иконки).
- `src/i18n.js` + `src/locales/*.js` — 7 языков (ru, en, uk, de, nl, fr, es). Ключ перевода — **русская строка из кода** (`t('Новый объект')`, подстановки `{name}`), множественное число — `tn(n, 'объект')`. Словари: `strings`, `plurals`, `help` (текст справки). Язык — `prefs.lang` (нет — язык системы), смена перезагружает страницу. Меню Electron переводится в `electron/menu-i18n.cjs` (страница шлёт язык через `window.desktop.setLang`).
- `electron/main.cjs` — окно, развёрнутое на весь экран (`maximize`, не полноэкранный режим — без отдельного стола macOS), меню (⌘Z/⇧⌘Z уходят странице через `preload.cjs` → `window.desktop.onMenu`).

## Важно не сломать

- **Z-fighting.** Стенки контейнеров (прозрачные или с содержимым) рисуются на 3 мм шире (`WALL_PAD`), пол теней не пишет глубину, `camera.near = 0.08`. Без этого грани вещей у стенок и дно контейнеров мерцают клетками.
- Цвета в CSS — только через переменные темы (`--ink`, `--glass`, `--acc`…), иначе светлые темы ломаются.
- Ключи localStorage `sklad3d:v1` / `sklad3d:prefs` оставлены от прототипа — не переименовывать без миграции.
- Новый текст в интерфейсе — только через `t('…')`, и сразу перевод во все словари; проверка `npm run i18n`. Константы верхнего уровня (названия тем, пресетов) не оборачивать в `t()` при объявлении — модули грузятся раньше `setLang`, переводить при показе.
- Окно настроек не масштабируется (`.modal.no-zoom`), иначе ползунок размера уезжает из-под курсора.
- Шрифт темы PixelArt — Nunito из `@fontsource` (локально, с кириллицей), без сети тоже работает.
